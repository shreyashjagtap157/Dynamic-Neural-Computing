# Phase 13B & 13D Freeze: Benchmark Contracts & Infrastructure

## 1. Scope & Status
This document formally freezes the benchmark contracts (Phase 13B) and benchmark infrastructure (Phase 13D) for the DNC v2.x empirical evaluation program. 

* **Status:** FROZEN
* **Baseline Software Version:** DNC v2.x Baseline v1.1 (140/140 tests passing)
* **Execution Framework:** `BenchmarkRunner` with deterministic seed management ($seed = base\_seed + rep$)

---

## 2. Benchmark Contracts (`src/dnc/evaluation/contracts.py`)

### `BenchmarkSystem` Abstract Protocol
Every evaluated system (baselines and DNC variants) must implement:
1. `initialize(workload_id: str, seed: int, config: Dict[str, Any]) -> None`
2. `execute(task_input: Dict[str, Any]) -> Dict[str, Any]`
3. `observe() -> Dict[str, Any]`
4. `get_result() -> ExperimentResult`
5. `shutdown() -> None`

### `ExperimentResult` Schema
Canonical result record generated by every experiment run:
* `experiment_id`: string
* `workload_id`: string
* `system_id`: string
* `seed`: integer
* `success`: boolean
* `task_quality`: float $[0.0, 1.0]$
* `latency_ms`: float
* `total_cost`: float
* `resource_usage`: float
* `execution_steps`: integer
* `adaptation_events`: integer
* `structural_mutations`: integer
* `recovery_events`: integer
* `provenance_reference`: optional string
* `metadata`: dictionary

## 4. Reproducibility & Integrity Guarantees
* Deterministic seeding: `random.seed(seed)` where `seed = base_seed + rep`.
* Equivalent workload task inputs across all systems.
* Isolated run environments with zero shared state across repetitions.
